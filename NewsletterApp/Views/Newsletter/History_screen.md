# History_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/Newsletter/History.cshtml
- **화면 이름**: 뉴스레터 수신 내역
- **화면 목적**: 발송된 뉴스레터 목록을 보고, 눌러서 본문을 팝업으로 본다. 로그인 뒤 첫 화면이다.
- **접근 URL**: /newsletters
- **접근 권한**: 일반 사용자(자신이 받은 것만), 관리자(전부). 로그인 안 했으면 `/login`으로 이동
- **시안 파일 경로**: 프로젝트/docs/mockups/history.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.
- 이 화면 시안은 일반 사용자 화면과 관리자 화면("구독자" 열, 관리자 메뉴)을 둘 다 보여준다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 | 열림 | `GET /api/newsletters?page=1`로 목록 표시 |
| 제목 | 클릭 | `GET /api/newsletters/{id}` → 본문 팝업 열기. NOT_FOUND면 알림 "뉴스레터를 찾을 수 없습니다." |
| 닫기 버튼 / 팝업 바깥 | 클릭 | 본문 팝업 닫기 (수신 내역 화면으로 돌아옴) |
| 페이지 버튼 | 클릭 | 그 페이지 목록 조회 |
| 메뉴 "뉴스레터 수신 내역" | 클릭 | 수신 내역 화면(`/newsletters`) |
| 메뉴 "내 구독" | 클릭 | 내 구독 화면(`/my/subscriptions`) |
| 메뉴 "회원 관리" (관리자) | 클릭 | 회원 관리 화면(`/admin/users`) |
| 메뉴 "구독" (관리자) | 클릭 | 구독 화면(`/admin/subscriptions`) |
| 메뉴 "뉴스레터 설정" (관리자) | 클릭 | 뉴스레터 설정 화면(`/admin/gubuns`) |
| 메뉴 "내 정보" | 클릭 | 내 정보 화면(`/my/profile`) |
| 로그아웃 버튼 | 클릭 | `POST /api/auth/logout` → 로그인 화면(`/login`) |
| (공통) | API가 401 응답 | 로그인 화면(`/login`)으로 이동 |
