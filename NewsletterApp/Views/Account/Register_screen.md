# Register_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/Account/Register.cshtml
- **화면 이름**: 회원가입
- **화면 목적**: 가입 정보를 입력하고 이메일 인증 코드를 확인한 뒤 가입한다.
- **접근 URL**: /register
- **접근 권한**: 비회원 (로그인했으면 `/newsletters`로 이동)
- **시안 파일 경로**: 프로젝트/docs/mockups/register.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 3. 화면 요소

| 요소 | 종류 | 표시 내용 | 데이터 출처 | 비고 |
|---|---|---|---|---|
| 제목 | 텍스트 | "회원가입" | 고정 | |
| 아이디 | 텍스트 입력 + 검사 문구 | 안내 "영문 소문자+숫자 6~20자" | 입력, `GET /api/auth/availability` | 필수, `maxlength=20` |
| 비밀번호 | 비밀번호 입력 + 검사 문구 | 안내 "8~20자, 영문·숫자·특수문자 각 1자 이상" | 입력 | 필수, `maxlength=20` |
| 비밀번호 확인 | 비밀번호 입력 + 검사 문구 | | 입력 | 필수, `maxlength=20` |
| 이메일 | 이메일 입력 + 검사 문구 | | 입력, `GET /api/auth/availability` | 필수, `maxlength=50` |
| 인증 코드 받기 버튼 | 버튼(보조) | "인증 코드 받기" / 보낸 뒤 "다시 받기" | 고정 | 이메일 검사를 통과해야 활성화 |
| 인증 코드 | 텍스트 입력 + 남은 시간 | "남은 시간 09:59" | 입력, 응답 `expiresInSeconds` | 코드를 보낸 뒤에만 보임, 숫자 6자리, `maxlength=6` |
| 인증 확인 버튼 | 버튼(보조) | "확인" | 고정 | 코드 6자리일 때 활성화 |
| 인증 상태 문구 | 텍스트 | "인증되었습니다." (초록) / 오류 (빨강) | API 응답 | |
| 이름 | 텍스트 입력 + 검사 문구 | 안내 "2~30자" | 입력 | 필수, `maxlength=30` |
| 오류 메시지 | 알림(빨간색) | 가입 실패 메시지 | API 오류 message | 평소 숨김 |
| 가입 버튼 | 버튼(기본색, 전체 너비) | "가입하기" | 고정 | 모든 칸 검사 통과 + 이메일 인증 완료일 때 활성화 |
| 로그인 링크 | 링크 | "이미 회원이신가요? 로그인" | 고정 | `/login` |

### 입력 즉시 검사 문구
| 칸 | 조건 | 문구 |
|---|---|---|
| 아이디 | 형식 틀림 | "영문 소문자와 숫자로 6~20자 입력해 주세요." |
| 아이디 | 형식 맞음, 입력 멈춘 뒤 0.4초에 중복 확인 | 사용 가능: "사용할 수 있는 아이디입니다." / 중복: "이미 사용 중인 아이디입니다." |
| 비밀번호 | 형식 틀림 | "8~20자, 영문·숫자·특수문자를 각 1자 이상 넣어 주세요." |
| 비밀번호 확인 | 다름 | "비밀번호가 같지 않습니다." |
| 이메일 | 형식 틀림 또는 50자 초과 | "올바른 이메일을 50자 이내로 입력해 주세요." |
| 이메일 | 형식 맞음, 0.4초 뒤 중복 확인 | 중복: "이미 사용 중인 이메일입니다." |
| 이름 | 앞뒤 공백 제외 2~30자 아님 | "이름을 2~30자로 입력해 주세요." |

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 각 입력 칸 | 입력 | 위 "입력 즉시 검사 문구"대로 바로 표시 |
| 이메일 | 인증 완료 뒤 값 변경 | 인증 상태를 지우고 다시 인증해야 함 |
| 인증 코드 받기 | 클릭 | `POST /api/auth/email-codes` → 성공하면 인증 코드 칸과 10분 남은 시간 표시, 버튼 문구 "다시 받기". 오류는 이메일 칸 아래에 표시 |
| 인증 확인 | 클릭 | `POST /api/auth/email-codes/verify` → 성공하면 "인증되었습니다.", 이메일·코드 칸 잠금. CODE_INVALID면 "인증 코드가 맞지 않습니다. (남은 횟수 n번)", CODE_EXPIRED면 해당 문구 |
| 남은 시간 | 0이 됨 | "인증 코드가 만료되었습니다. 다시 받아 주세요." 표시, 확인 버튼 비활성화 |
| 가입 버튼 | 클릭 | `POST /api/auth/register` → 성공하면 알림 "가입되었습니다. 로그인해 주세요." 뒤 로그인 화면(`/login`)으로 이동. 오류는 오류 메시지에 표시 (DUPLICATE_*는 그 칸 아래에도 표시) |
| 로그인 링크 | 클릭 | 로그인 화면(`/login`)으로 이동 |

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 기본 | 빈 입력 칸, 인증 코드 칸 숨김, 가입 버튼 비활성화 |
| 입력 오류 | 해당 칸 빨간 테두리와 검사 문구 |
| 입력 통과 | 해당 칸 초록 테두리 (아이디는 "사용할 수 있는 아이디입니다.") |
| 코드 보냄 | 인증 코드 칸, 남은 시간, "다시 받기" 버튼 |
| 인증 완료 | "인증되었습니다." (초록), 이메일·코드 칸 잠금 |
| 로딩 중 | 누른 버튼 비활성화와 작은 스피너 |
| 데이터 없음 | 해당 없음 (조회 데이터 없음) |
| 오류 | 오류 메시지(빨간 알림)에 API 메시지, 서버 오류는 "일시적인 오류가 발생했습니다. 잠시 뒤에 다시 시도해 주세요." |
