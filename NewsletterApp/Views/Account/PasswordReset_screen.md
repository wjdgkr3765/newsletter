# PasswordReset_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/Account/PasswordReset.cshtml
- **화면 이름**: 비밀번호 찾기
- **화면 목적**: 아이디와 이메일을 확인하고 인증 코드를 확인한 뒤, 같은 화면에서 새 비밀번호를 정한다.
- **접근 URL**: /password-reset
- **접근 권한**: 비회원 (로그인했으면 `/newsletters`로 이동)
- **시안 파일 경로**: 프로젝트/docs/mockups/password_reset.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 아이디, 이메일 | 입력 | 형식 검사 문구 즉시 표시 (회원가입과 같은 문구) |
| 인증 코드 받기 | 클릭 | `POST /api/auth/password-reset/codes` → 성공하면 인증 코드 칸과 남은 시간 표시. MEMBER_NOT_MATCHED면 오류 메시지 "아이디와 이메일이 일치하는 회원이 없습니다." |
| 인증 확인 | 클릭 | `POST /api/auth/password-reset/codes/verify` → 성공하면 "인증되었습니다.", 1단계 칸 잠금, 2단계 영역 표시. 실패 문구는 회원가입과 같음 |
| 남은 시간 | 0이 됨 | "인증 코드가 만료되었습니다. 다시 받아 주세요." |
| 새 비밀번호, 확인 | 입력 | 형식, 일치 검사 문구 즉시 표시 |
| 변경 버튼 | 클릭 | `POST /api/auth/password-reset` → 성공하면 알림 "비밀번호를 바꿨습니다. 로그인해 주세요." 뒤 로그인 화면(`/login`)으로 이동 |
| 로그인 링크 | 클릭 | 로그인 화면(`/login`)으로 이동 |

## 5. 데이터

### 사용 API
| 메서드 | 경로 | 용도 |
|---|---|---|
| POST | /api/auth/password-reset/codes | 인증 코드 보내기 |
| POST | /api/auth/password-reset/codes/verify | 인증 코드 확인 |
| POST | /api/auth/password-reset | 새 비밀번호 저장 |

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 기본 | 아이디·이메일 칸, 인증 코드 칸과 2단계 영역 숨김 |
| 입력 오류 | 해당 칸 빨간 테두리와 검사 문구 |
| 회원 불일치 | 오류 메시지 "아이디와 이메일이 일치하는 회원이 없습니다." |
| 코드 보냄 | 인증 코드 칸, 남은 시간, "다시 받기" 버튼 |
| 인증 완료 | "인증되었습니다.", 1단계 잠금, 2단계 영역 표시 |
| 로딩 중 | 누른 버튼 비활성화와 작은 스피너 |
| 데이터 없음 | 해당 없음 (조회 데이터 없음) |
| 오류 | 오류 메시지에 API 메시지, 서버 오류는 "일시적인 오류가 발생했습니다. 잠시 뒤에 다시 시도해 주세요." |
