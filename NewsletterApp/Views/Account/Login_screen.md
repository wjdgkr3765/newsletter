# Login_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/Account/Login.cshtml
- **화면 이름**: 로그인
- **화면 목적**: 아이디와 비밀번호로 로그인한다.
- **접근 URL**: /login
- **접근 권한**: 비회원 (로그인했으면 `/newsletters`로 이동)
- **시안 파일 경로**: 프로젝트/docs/mockups/login.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 3. 화면 요소

| 요소 | 종류 | 표시 내용 | 데이터 출처 | 비고 |
|---|---|---|---|---|
| 제목 | 텍스트 | "뉴스레터 로그인" | 고정 | |
| 아이디 | 텍스트 입력 | 자리표시 "아이디" | 입력 | 필수, 최대 20자 (`maxlength=20`) |
| 비밀번호 | 비밀번호 입력 | 자리표시 "비밀번호" | 입력 | 필수, 최대 20자 |
| 오류 메시지 | 알림(빨간색) | 로그인 실패·잠금·서버 오류 메시지 | API 오류 message | 평소에는 숨김 |
| 로그인 버튼 | 버튼(기본색, 전체 너비) | "로그인" | 고정 | 요청 중에는 비활성화 |
| 회원가입 링크 | 링크 | "회원가입" | 고정 | `/register` |
| 비밀번호 찾기 링크 | 링크 | "비밀번호 찾기" | 고정 | `/password-reset` |

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 로그인 버튼 | 클릭 또는 입력 칸에서 Enter | 아이디·비밀번호가 비어 있으면 그 칸 아래에 "아이디를 입력해 주세요." / "비밀번호를 입력해 주세요." 표시. 아니면 `POST /api/auth/login` |
| 로그인 버튼 | 응답 성공 | `redirectUrl`(`/newsletters`, 수신 내역 화면)로 이동 |
| 로그인 버튼 | 응답 LOGIN_FAILED | 오류 메시지 "아이디 또는 비밀번호가 맞지 않습니다.", 비밀번호 칸 비움 |
| 로그인 버튼 | 응답 LOGIN_LOCKED | 오류 메시지 "로그인 시도가 많아 10분 뒤에 다시 시도해 주세요." |
| 회원가입 링크 | 클릭 | 회원가입 화면(`/register`)으로 이동 |
| 비밀번호 찾기 링크 | 클릭 | 비밀번호 찾기 화면(`/password-reset`)으로 이동 |

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 기본 | 빈 입력 칸, 오류 메시지 숨김 |
| 입력 누락 | 비어 있는 칸 빨간 테두리와 그 아래 안내 문구 |
| 로딩 중 | 로그인 버튼 비활성화, 버튼 안에 작은 스피너와 "로그인 중" |
| 데이터 없음 | 해당 없음 (조회 데이터 없음) |
| 로그인 실패 | 오류 메시지 "아이디 또는 비밀번호가 맞지 않습니다." |
| 로그인 잠금 | 오류 메시지 "로그인 시도가 많아 10분 뒤에 다시 시도해 주세요." |
| 오류 | 오류 메시지 "일시적인 오류가 발생했습니다. 잠시 뒤에 다시 시도해 주세요." |
