# Unsubscribe_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/Unsubscribe/Unsubscribe.cshtml
- **화면 이름**: 수신 거부
- **화면 목적**: 메일의 수신 거부 링크로 열려, 종류를 확인한 뒤 버튼을 눌러 그 종류의 구독을 해지한다.
- **접근 URL**: /unsubscribe?token={토큰}
- **접근 권한**: 링크를 받은 회원 (로그인 불필요, 로그인 여부와 관계없이 같은 화면)
- **시안 파일 경로**: 프로젝트/docs/mockups/unsubscribe.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 | 메일의 수신 거부 링크로 열림 | 컨트롤러가 토큰을 풀고 회원·종류가 있는지 확인한다. 있으면 안내 문구와 버튼, 없으면 링크 오류 문구. 구독은 바꾸지 않는다 |
| 수신 거부 버튼 | 클릭 | `POST /api/unsubscribe` → 성공하면(이미 해지된 상태도 성공) 완료 문구와 로그인 링크, 버튼 숨김. INVALID_LINK면 링크 오류 문구 |
| 로그인 링크 | 클릭 | 로그인 화면(`/login`)으로 이동 (로그인되어 있으면 수신 내역으로 이동) |

## 5. 데이터

### 사용 API
| 메서드 | 경로 | 용도 |
|---|---|---|
| POST | /api/unsubscribe | 수신 거부 (구독 해지) |

- 화면을 열 때 종류 이름은 API가 아니라 `UnsubscribeController`가 `UnsubscribeTokenService`로 토큰을 풀어 뷰에 넘긴다.

### 사용 테이블
- users, gubuns, subscriptions
