# MySubscriptions_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/My/MySubscriptions.cshtml
- **화면 이름**: 내 구독
- **화면 목적**: 모든 뉴스레터 종류와 발송 시간을 보고, 스위치로 바로 구독·해지한다.
- **접근 URL**: /my/subscriptions
- **접근 권한**: 일반 사용자, 관리자 (자기 구독만). 로그인 안 했으면 `/login`으로 이동
- **시안 파일 경로**: 프로젝트/docs/mockups/my_subscriptions.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 | 열림 | `GET /api/me/subscriptions`로 표 표시 |
| 검색 버튼, 검색창 Enter | 클릭, Enter | 앞뒤 공백을 뺀 검색어로 1페이지부터 다시 조회(`keyword`). 빈 칸이면 전체 목록 |
| 구독 스위치 | 켬 | 그 스위치 비활성화 → `POST /api/me/subscriptions` (`isSubscribed: true`) → 성공하면 다시 활성화. 실패하면 스위치를 끔으로 되돌리고 오류 알림 |
| 구독 스위치 | 끔 | 위와 같고 `isSubscribed: false`, 실패하면 켬으로 되돌림 |
| 메뉴 항목, 로그아웃 | 클릭 | History_screen.md "4. 동작"의 메뉴 이동과 같음 (수신 내역, 내 구독, 내 정보, 관리자 메뉴, 로그아웃 → `/login`) |
| (공통) | API가 401 응답 | 로그인 화면(`/login`)으로 이동 |

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 로딩 중 | 표 자리에 스피너와 "불러오는 중" |
| 데이터 없음 | 표 안에 "등록된 뉴스레터 종류가 없습니다." |
| 검색 결과 없음 | 표 안에 "검색 결과가 없습니다." |
| 목록 있음 | 종류, 발송 시간("매일 HH:mm" 또는 "지금은 발송하지 않음"), 스위치 |
| 저장 중 | 그 스위치만 비활성화 |
| 오류 (목록) | 빨간 알림 "목록을 불러오지 못했습니다." 와 "다시 시도" 버튼 |
| 오류 (저장) | 스위치 되돌림, 빨간 알림에 API 메시지 |
