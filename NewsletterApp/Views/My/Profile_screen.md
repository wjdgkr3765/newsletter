# Profile_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/My/Profile.cshtml
- **화면 이름**: 내 정보
- **화면 목적**: 이름·이메일을 수정하고, 비밀번호를 바꾸고, 탈퇴한다.
- **접근 URL**: /my/profile
- **접근 권한**: 일반 사용자, 관리자 (자기 정보만, 관리자는 탈퇴 불가). 로그인 안 했으면 `/login`으로 이동
- **시안 파일 경로**: 프로젝트/docs/mockups/profile.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.
- 이 화면 시안은 일반 사용자의 탈퇴 영역과 관리자의 안내 문구를 둘 다 보여준다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 | 열림 | `GET /api/me`로 값 채움, `isAdmin`에 따라 탈퇴 영역 결정 |
| 이름, 이메일 | 입력 | 형식 검사 문구 즉시 표시. 이메일이 지금과 다르면 인증 코드 받기 버튼 표시, 같으면 숨김 |
| 인증 코드 받기 | 클릭 | `POST /api/me/email-codes` → 코드 칸, 남은 시간 표시. SAME_EMAIL, DUPLICATE_EMAIL은 이메일 칸 아래 표시 |
| 인증 확인 | 클릭 | `POST /api/me/email-codes/verify` → "인증되었습니다.", 이메일 칸 잠금 |
| 저장 버튼 | 클릭 | `POST /api/me/profile` → 성공하면 "저장했습니다.", 메뉴의 회원 이름 갱신, 인증 영역 초기화 |
| 비밀번호 변경 버튼 | 클릭 | `POST /api/me/password` → 성공하면 "비밀번호를 바꿨습니다.", 세 칸 비움 (로그인 유지). WRONG_PASSWORD는 현재 비밀번호 칸 아래 표시 |
| 탈퇴 버튼 | 클릭 | 탈퇴 확인 팝업 열기 |
| 팝업 취소 | 클릭 | 팝업 닫기 (내 정보 화면) |
| 팝업 탈퇴 | 클릭 | 비밀번호가 비어 있으면 "비밀번호를 입력해 주세요." 아니면 `POST /api/me/withdraw` → 성공하면 알림 "탈퇴했습니다." 뒤 로그인 화면(`/login`)으로 이동. WRONG_PASSWORD는 팝업 안에 표시 |
| 메뉴 항목, 로그아웃 | 클릭 | History_screen.md "4. 동작"의 메뉴 이동과 같음 (수신 내역, 내 구독, 내 정보, 관리자 메뉴, 로그아웃 → `/login`) |
| (공통) | API가 401 응답 | 로그인 화면(`/login`)으로 이동 |

## 5. 데이터

### 사용 API
| 메서드 | 경로 | 용도 |
|---|---|---|
| GET | /api/me | 내 정보 |
| POST | /api/me/email-codes | 새 이메일로 인증 코드 보내기 |
| POST | /api/me/email-codes/verify | 인증 코드 확인 |
| POST | /api/me/profile | 이름·이메일 저장 |
| POST | /api/me/password | 비밀번호 변경 |
| POST | /api/me/withdraw | 회원 탈퇴 |
| POST | /api/auth/logout | 로그아웃 (공통 레이아웃) |

### 사용 테이블
- users, subscriptions, historys

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 로딩 중 | 본문에 스피너와 "불러오는 중" |
| 데이터 없음 | 해당 없음 (로그인한 회원은 항상 정보가 있음. 없어졌으면 401과 같이 로그인 화면으로) |
| 기본 (일반 사용자) | 세 카드, 탈퇴 버튼 |
| 기본 (관리자) | 세 카드, 탈퇴 버튼 대신 "관리자는 탈퇴할 수 없습니다." |
| 이메일 변경 중 | 인증 코드 받기 버튼, 코드 칸, 남은 시간 |
| 이메일 인증 완료 | "인증되었습니다.", 이메일 칸 잠금 |
| 입력 오류 | 해당 칸 빨간 테두리와 검사 문구 |
| 저장 완료 | 카드 안 초록 알림 |
| 탈퇴 확인 팝업 | 팝업 표시 |
| 저장 중 | 누른 버튼 비활성화와 작은 스피너 |
| 오류 | 카드 안 빨간 알림에 API 메시지, 서버 오류는 "일시적인 오류가 발생했습니다. 잠시 뒤에 다시 시도해 주세요." |
