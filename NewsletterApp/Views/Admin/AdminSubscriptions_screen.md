# AdminSubscriptions_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/Admin/AdminSubscriptions.cshtml
- **화면 이름**: 구독 (구독 관리)
- **화면 목적**: 종류를 골라 회원별 체크박스로 바로 구독·해지한다.
- **접근 URL**: /admin/subscriptions
- **접근 권한**: 관리자. 로그인 안 했으면 `/login`, 일반 사용자는 `/newsletters`로 이동
- **시안 파일 경로**: 프로젝트/docs/mockups/admin_subscriptions.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.
- 이 화면 시안은 '전체'(체크박스 없음)와 종류 선택(체크박스 있음)을 둘 다 보여준다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 | 열림 | `GET /api/admin/gubuns`로 드롭다운 채움, `GET /api/admin/subscriptions?page=1`('전체') |
| 종류 드롭다운 | 변경 | 1페이지부터 `GET /api/admin/subscriptions?gubunId={id}&page=1` (전체면 gubunId 없이). 종류면 체크박스 열 표시 |
| 구독 체크박스 | 체크 | 그 체크박스 비활성화 → `POST /api/admin/subscriptions` (`isSubscribed: true`) → 성공하면 활성화. 실패하면 체크를 되돌리고 오류 알림 |
| 구독 체크박스 | 체크 해제 | 위와 같고 `isSubscribed: false`, 실패하면 다시 체크 |
| 페이지 버튼 | 클릭 | 지금 고른 종류로 그 페이지 조회 |
| 메뉴 항목, 로그아웃 | 클릭 | History_screen.md "4. 동작"의 메뉴 이동과 같음 (수신 내역, 내 구독, 회원 관리, 구독, 뉴스레터 설정, 내 정보, 로그아웃 → `/login`) |
| (공통) | API가 401 응답 | 로그인 화면(`/login`)으로 이동 |

## 5. 데이터

### 사용 API
| 메서드 | 경로 | 용도 |
|---|---|---|
| GET | /api/admin/gubuns | 드롭다운 종류 목록 |
| GET | /api/admin/subscriptions | 회원 목록과 구독 여부 |
| POST | /api/admin/subscriptions | 구독·해지 |
| POST | /api/auth/logout | 로그아웃 (공통 레이아웃) |

### 사용 테이블
- users, gubuns, subscriptions

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 로딩 중 | 표 자리에 스피너와 "불러오는 중" |
| 데이터 없음 | 표 안에 "회원이 없습니다." |
| 전체 | 이름, 이메일 열만 (체크박스 없음) |
| 종류 선택 | 체크박스, 이름, 이메일 열. 구독한 회원 체크 |
| 저장 중 | 그 체크박스만 비활성화 |
| 종류 없음 | 드롭다운에 '전체'만 |
| 오류 | 빨간 알림 (목록 실패는 "목록을 불러오지 못했습니다." 와 "다시 시도" 버튼, 저장 실패는 API 메시지) |
