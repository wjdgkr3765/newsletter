# Users_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/Admin/Users.cshtml
- **화면 이름**: 회원 관리
- **화면 목적**: 회원 목록을 보고 회원을 정지하거나 정지를 푼다.
- **접근 URL**: /admin/users
- **접근 권한**: 관리자. 로그인 안 했으면 `/login`, 일반 사용자는 `/newsletters`로 이동
- **시안 파일 경로**: 프로젝트/docs/mockups/users.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 | 열림 | `GET /api/admin/users?page=1` |
| 정지 / 정지 해제 버튼 | 클릭 | 확인 팝업 열기 |
| 확인 팝업 취소 | 클릭 | 팝업 닫기 |
| 확인 팝업 확인 | 클릭 | 확인 버튼 비활성화 → `POST /api/admin/users/{id}/suspension` → 성공하면 팝업 닫고 그 행의 상태·버튼 갱신, 알림. CANNOT_SUSPEND_SELF 등 오류는 알림 |
| 페이지 버튼 | 클릭 | 그 페이지 조회 |
| 메뉴 항목, 로그아웃 | 클릭 | History_screen.md "4. 동작"의 메뉴 이동과 같음 (수신 내역, 내 구독, 회원 관리, 구독, 뉴스레터 설정, 내 정보, 로그아웃 → `/login`) |
| (공통) | API가 401 응답 | 로그인 화면(`/login`)으로 이동 |
