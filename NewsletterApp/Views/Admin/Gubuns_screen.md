# Gubuns_screen.md

화면 설계 문서다. 원본 템플릿은 `docs/screen.md`다. 화면을 바꾸는 작업에서는 이 문서도 함께 갱신한다.

---

## 1. 기본 정보

- **화면 파일 경로**: 프로젝트/NewsletterApp/Views/Admin/Gubuns.cshtml
- **화면 이름**: 뉴스레터 설정 (종류 목록)
- **화면 목적**: 뉴스레터 종류와 발송 설정을 보고, 종류를 추가하고, 종류를 골라 발송 설정 상세로 이동한다.
- **접근 URL**: /admin/gubuns
- **접근 권한**: 관리자. 로그인 안 했으면 `/login`, 일반 사용자는 `/newsletters`로 이동
- **시안 파일 경로**: 프로젝트/docs/mockups/gubuns.html

### 시안 작성 규칙
- 파일명은 화면 파일명을 snake_case로 쓴다. (예: `Register.cshtml` → `register.html`)
- 프로젝트의 부트스트랩을 상대 경로로 불러와 실제 화면과 같은 스타일로 만든다. 서버 없이 파일을 바로 열어 볼 수 있어야 한다.
- 기능 없이 화면 모양과 "6. 상태별 화면"의 상태만 보여준다.
- 설계가 바뀌면 시안도 함께 고친다.

## 4. 동작

| 요소 | 사용자 동작 | 결과 |
|---|---|---|
| 화면 | 열림 | `GET /api/admin/gubuns`로 표 표시 |
| 검색 버튼, 검색창 Enter | 클릭, Enter | 앞뒤 공백을 뺀 검색어로 1페이지부터 다시 조회(`keyword`). 빈 칸이면 전체 목록 |
| 종류 표 행 | 클릭 | 발송 설정 상세 화면(`/admin/gubuns/{id}`)으로 이동 |
| 종류 추가 버튼 | 클릭 | 팝업 열기 (입력값을 기본값으로 초기화: 이름 빈칸, 16:00, 사용 안 함) |
| 종류 이름 | 입력 | 비었거나 20자 초과면 "종류 이름을 1~20자로 입력해 주세요." |
| 사용 여부 스위치 | 켬/끔 | 라벨만 "사용"/"사용 안 함"으로 바뀐다. 저장하지 않는다 |
| 취소 버튼 | 클릭 | 팝업 닫기, 저장하지 않음 |
| 추가 버튼 | 클릭 | `POST /api/admin/gubuns` → 성공하면 팝업 닫고 지금 검색어로 목록 다시 조회, 알림. DUPLICATE_GUBUN_NAME은 이름 칸 아래 "이미 있는 종류 이름입니다." |
| 메뉴 항목, 로그아웃 | 클릭 | History_screen.md "4. 동작"의 메뉴 이동과 같음 (수신 내역, 내 구독, 회원 관리, 구독, 뉴스레터 설정, 내 정보, 로그아웃 → `/login`) |
| (공통) | API가 401 응답 | 로그인 화면(`/login`)으로 이동 |

## 6. 상태별 화면

| 상태 | 표시 내용 |
|---|---|
| 로딩 중 | 표 자리에 스피너와 "불러오는 중" |
| 데이터 없음 | 표 안에 "등록된 종류가 없습니다. '종류 추가'로 추가해 주세요." |
| 검색 결과 없음 | 표 안에 "검색 결과가 없습니다." |

| 입력 오류 | 이름 칸 빨간 테두리와 검사 문구 |
| 저장 중 | 추가 버튼 비활성화와 스피너 |
| 오류 | 목록 실패는 빨간 알림 "목록을 불러오지 못했습니다." 와 "다시 시도" 버튼, 추가 실패는 팝업 안 빨간 알림 |
